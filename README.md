# Система учета заказов

## Назначение

Приложение предназначено для учета и обработки заказов клиентов. Система позволяет хранить информацию о заказах, связанных с ними товарах и отслеживать текущий статус выполнения заказа.

## Целевая аудитория

Сотрудники организаций, работающих с заказами клиентов: менеджеры, операторы и администраторы.

## Предметная область

Предметная область проекта — учет заказов клиентов. Каждый заказ создается для определенного клиента, содержит информацию о товаре и имеет текущий статус, отражающий этап его обработки.

## Основные сущности

- Клиент — пользователь, оформляющий заказ.
- Заказ — информация о заказе клиента.
- Товар — объект, который входит в заказ.
- Статус — текущее состояние заказа.

## Основные функции

- Создание нового заказа.
- Расчет стоимости заказа.
- Определение и отображение текущего статуса заказа.
- Просмотр информации о заказе.
- Изменение статуса заказа.

## План развития

На следующих этапах планируется:

- расширение функциональности консольной программы;
- реализация основных сущностей в виде классов;
- разработка веб-приложения на Django;
- подключение базы данных;
- реализация регистрации и авторизации пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
