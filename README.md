# Система учета заказов

Консольное приложение для менеджеров и операторов: учет клиентов,
товаров в заказах и готовности заказов к выдаче. Доработка проекта ПР1
по требованиям ПР2 «Основы Python: коллекции, функции, циклы
и расширенные возможности Python».

## Возможности

- Просмотр и добавление клиентов, поиск по имени без учета регистра.
- Удаление клиента, если у него нет заказов.
- Создание заказа для существующего клиента; проверка цены и количества.
- Просмотр заказов с именем клиента, стоимостью и текстовым статусом.
- Поиск по клиенту и подстроке названия товара.
- Изменение статуса: в обработке / готов к выдаче.
- Удаление (отмена) заказа.
- Фильтрация по статусу; сортировка по сумме, товару или ID в обе стороны.
- Статистика: количество заказов, готовые и обрабатываемые заказы,
  число клиентов с заказами, общая сумма.
- Загрузка JSON при запуске, сохранение после каждого изменения.

## Запуск

Требуется Python 3.10 или новее. Код приложения использует стандартную
библиотеку; pytest и flake8 нужны для разработки.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

## Структура проекта

- `main.py` — меню, вывод, обработка ошибок, сохранение изменений.
- `clients.py` — операции над клиентами, проверка их данных.
- `orders.py` — операции над заказами, поиск, генератор фильтрации,
  сортировка и статистика.
- `storage.py` — общая логика чтения и записи JSON, функции для двух сущностей.
- `utils.py` — ввод чисел и генерация идентификаторов.
- `data/clients.json`, `data/orders.json` — данные приложения.
- `tests/test_project.py` — автоматизированные проверки.
- `requirements.txt` — инструменты тестирования и проверки оформления.
- `pytest.ini` — пути импорта и каталог тестов.

## Формат данных и ограничения

Каждый JSON-файл содержит список словарей. Пример одного клиента:

```json
{"id": 1, "name": "Иван Иванов", "phone": "2234562"}
```

Пример заказа:

```json
{
  "id": 1,
  "client_id": 1,
  "product_name": "Клавиатура",
  "price": 3500.0,
  "quantity": 2,
  "is_ready": false
}
```

Сохраняются обычные JSON-файлы через `with open`. После изменения данных
и при выборе 0 программа сохраняет оба списка. При ошибке записи изменения
остаются в памяти: выберите 0 для повторной попытки. Ctrl+C завершает работу
без повторного сохранения. Защиты от частичной записи при сбое нет.

Отсутствующий файл означает пустой список. Ошибка чтения JSON останавливает
запуск с сообщением. Полной проверки полей загруженных записей нет:
при ручном редактировании соблюдайте показанный формат и уникальность ID.
При добавлении проверяются пустые строки, положительные цена и количество,
наличие клиента. Целое количество обеспечивает функция ввода `input_int`.

## Проверки

```sh
python -m pytest
python -m flake8
```

Пять тестов проверяют добавление клиента, поиск заказа, расчет стоимости,
неизвестного клиента и сохранение/загрузку JSON.
